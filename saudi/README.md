# 🩺 Saudi Anesthesia Board QB Practice

An interactive, mobile-optimized active recall revision suite tailored for candidates preparing for the **Saudi Board in Anesthesia** examinations.

---

### ✨ Key Features

* **Curated Subspecialty Question Banks:** Modular modules covering Core Anesthesia, Regional Anesthesia, Airway Management, Equipment & Physics, Hemodynamics, Neuroanesthesia, Obstetric Anesthesia, Pediatric Anesthesia, and Pharmacology.
* **Active Recall & Rationale:** Step-by-step rationales accompanied by verified citations from standard references (*Miller’s Anesthesia*, *Barash Clinical Anesthesia*, *Morgan & Mikhail*, *Stoelting*, and *ASRA Guidelines*).
* **Multi-Device Cloud Synchronization:** Real-time synchronization of question progress, accuracy scores, and bookmarked questions across iOS, iPadOS, and desktop browsers via Firebase and Cloud Firestore.
* **Dual Authentication:** 1-Click Google Sign-In alongside traditional Email/Password authentication with password reset capabilities.
* **Targeted Practice Modes:** Support for sequential review or randomized/shuffled question delivery with real-time performance metrics.
* **Zero-Build Architecture:** Lightweight, client-side static application styled with Tailwind CSS and Lucide icons, deployable directly on GitHub Pages.

---

### 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (ES6+)
* **Icons:** Lucide Icons
* **Backend & Database:** Firebase Authentication, Cloud Firestore
* **Hosting:** GitHub Pages
